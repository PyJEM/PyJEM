    "## Appendix:\n",
    "\n",
    "To use PyJEM from another PC\n",
    "When PyJEM is used on TEMPC, it works with the default settings.\n",
    "However, **when PyJEM is used from a PC other than TEMPC (remote PC)**, additional configuration is required so that PyJEM can connect to TEMPC correctly.\n",
    "\n",
    "This page describes the two setup steps required to use PyJEM from a remote PC.\n",
    "\n",
    "### Required setup\n",
    "\n",
    "```text\n",
    "Using PyJEM from a remote PC\n",
    "├── 1. Change the PyJEM connection settings (config)\n",
    "│   └── Set the IP address of TEMPC that PyJEM communicates with\n",
    "└── 2. Install TEMExternal and enable remote settings\n",
    "    └── Enable communication between the remote PC and TEMPC\n",
    "```\n",
    "\n",
    "### 1. Change the PyJEM connection settings (config)\n",
    "\n",
    "By default, PyJEM is configured to connect to the local PC (TEMPC).\n",
    "When running PyJEM from a remote PC, you must specify the IP address of TEMPC as the connection target.\n",
    "\n",
    "Configuration items to update:\n",
    "- IP address of TEMPC\n",
    "- Connection target used by PyJEM for communication\n",
    "\n",
    "### 2. Install TEMExternal and enable remote settings\n",
    "\n",
    "Install TEMExternal on the remote PC that will execute the PyJEM scripts, and enable remote communication.\n",
    "This allows PyJEM on the remote PC to communicate with the JEOL control software through TEMPC.\n",
    "\n",
    "Setup items:\n",
    "- Install TEMExternal on the remote PC\n",
    "- Enable remote communication settings\n",
    "- Confirm that the remote PC can reach TEMPC over the network"
