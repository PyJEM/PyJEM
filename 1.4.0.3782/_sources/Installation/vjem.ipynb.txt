    "## Step 2. vjem\n",
    "\n",
    "vjem is a conda-based Python virtual environment that contains all the libraries required to run PyJEM.\n",
    "Conda virtual environments provide isolated Python and library environments for each project, preventing dependency conflicts.\n",
    "This makes it possible to safely use different versions of packages side by side, allowing you to separate and manage development and experimental work independently.\n",
    "\n",
    "[Forum](https://github.com/PyJEM/PyJEM#vjem-python-virtual-environment) provides various python versions of vjem. You can download the YML file and generate the environment in the online environment .\n",
    "\n",
    "<img src=\"../_static/forum_vjem_page.png\" width=\"50%\">\n",
    "\n",
    "### PyJEM Setup Guide: Installing vjem38 Environment\n",
    "\n",
    "PyJEM requires a dedicated Python environment. We recommend using `vjem`, a Conda-based virtual environment tailored for PyJEM.\n",
    "\n",
    "#### Step 1: Download the YAML File\n",
    "\n",
    "Visit the [PyJEM GitHub Releases](https://github.com/PyJEM/PyJEM/releases) and download the appropriate YAML file for your Python version.\n",
    "\n",
    "**Recommended: Python 3.8 → `vjem38.yml`**\n",
    "\n",
    "<img src=\"../_static/download_vjem38.png\" width=\"50%\">\n",
    "\n",
    "#### Step 2: Create the Conda Environment\n",
    "Open your terminal and navigate to the folder containing the downloaded `.yml` file. Then run:\n",
    "\n",
    "```\n",
    "conda env create -f vjem_yml\n",
    "```\n",
    "\n",
    "※ *vjem_yml* is yml file's absolute path that has downloaded.\n",
    "\n",
    "#### Step 3. Verify the Environment\n",
    "You the vjem has been created.\n",
    "\n",
    "```\n",
    "> conda info --envs\n",
    "```\n",
    "If there is no error in activate, the environment has been successfully built."
