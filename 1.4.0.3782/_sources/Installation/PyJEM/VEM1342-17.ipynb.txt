    "## VEM1342-17\n",
    "\n",
    "\n",
    "This document explains the PyJEM package installation procedure.\n",
    "\n",
    "### Overall Flow\n",
    "1. Confirm the license agreement\n",
    "2. Select PyJEM and installation options\n",
    "3. Select the target virtual environment\n",
    "4. Review settings and start installation\n",
    "5. Check the result and finish\n",
    "\n",
    "### 1. License Agreement\n",
    "Purpose: Enable installation by accepting the license terms.\n",
    "\n",
    "**Procedure:**\n",
    "1. Read the license text shown in the installer window.\n",
    "2. If there are no issues with the terms, enable the agreement option.\n",
    "3. Click Next to continue to the next screen.\n",
    "\n",
    "<img src=\"../../_static/PyJEM_installer/vem1342-17_0.png\" width=\"50%\">\n",
    "\n",
    "### 2. Select PyJEM\n",
    "Purpose: Decide which PyJEM package and optional settings to install.\n",
    "\n",
    "**Procedure:**\n",
    "1. Select the PyJEM package to install.\n",
    "2. Check the required optional items.\n",
    "3. Click [Next] to continue to the next screen.\n",
    "\n",
    "<img src=\"../../_static/PyJEM_installer/vem1342-17_1.png\" width=\"50%\">\n",
    "\n",
    "**PyJEM to install:**\n",
    "| Item | Description |\n",
    "|:---|:---|\n",
    "| Use included | Installs the PyJEM package bundled with this installer. |\n",
    "| Use other (.whl/.zip) | Installs a package file you specify, downloaded from the [Forum](https://github.com/PyJEM/PyJEM/releases). |\n",
    "\n",
    "**Options:**\n",
    "| Item | Description |\n",
    "|:---|:---|\n",
    "| Make document shortcut on Desktop | Creates a desktop shortcut to the PyJEM documentation. |\n",
    "| Setup on remote PC | Applies settings for installing PyJEM on a PC other than TEMPC. |\n",
    "\n",
    "### 3. Select the python environment\n",
    "Purpose: Specify the Python environment where PyJEM will be installed.\n",
    "\n",
    "**Procedure:**\n",
    "1. Select the install destination environment for the PyJEM package chosen in Step 2.\n",
    "2. Confirm that the recommended environment vjem is selected.\n",
    "3. If needed, add another environment using Add.\n",
    "4. Click [Next] to continue to the next screen.\n",
    "\n",
    "<img src=\"../../_static/PyJEM_installer/vem1342-17_2.png\" width=\"50%\">\n",
    "\n",
    "**How to Add Another Environment:**\n",
    "1. Click [Add].\n",
    "2. In the pop-up window, select the target environment's python.exe.\n",
    "\n",
    "Ex) in case of vjem310:\n",
    "\n",
    "  C:\\Users\\Public\\Documents\\JEOL\\python\\envs\\vjem310\\pythonw.exe\n",
    "\n",
    "### 4. Start Installation\n",
    "Purpose: Prevent configuration mistakes before executing installation.\n",
    "\n",
    "**Procedure:**\n",
    "1. Review all selected settings (package, options, and environment).\n",
    "2. If something is incorrect, click [Back] and fix it.\n",
    "3. If everything is correct, click [Install] to start.\n",
    "\n",
    "<img src=\"../../_static/PyJEM_installer/vem1342-17_3.png\" width=\"50%\">\n",
    "\n",
    "### 5. Check Installation Result\n",
    "\n",
    "**Procedure:**\n",
    "1. On the result screen, confirm the status (Success/Failure).\n",
    "\n",
    "<img src=\"../../_static/PyJEM_installer/vem1342-17_result.png\" width=\"50%\">\n",
    "\n",
    "**Checkpoints:**\n",
    "- No error message is shown.\n",
    "- A successful status is displayed.\n",
    "\n",
    "### Notes\n",
    "- If installation fails, recheck the vjem environment status and selected options, then retry.\n",
    "- If administrator privileges are required, run the installer as administrator."
