class PyJEM.TEM3.event.EventManager(*args, **kwargs)¶

Bases: object

set_enabled(event_name, enabled)¶

Configure whether events specified by ‘event_name’ should be queued.

Parameters:

  • event_name (str) – Event name. refer to EventKind Enum.

  • enabled (bool) – set to True to enable queuing, False to disable.

Return type:

None

Examples

>>> TEM3.EventManager().set_enabled("ChgMag", False)
>>> TEM3.EventManager().queue_info().get("ChgMag").get("enabled")
False
set_maxsize(event_name, maxsize)¶

Set max size of the queue for the selected event.

Parameters:

  • event_name (str) – Event name. refer to EventKind Enum.

  • maxsize (int) – queue size. default is 10.

Return type:

None

Examples

>>> TEM3.EventManager().set_maxsize("ChgMag", False)
>>> TEM3.EventManager().queue_info().get("ChgMag").get("maxsize")
100
put_event(event_name, data=None)¶

Add an event to the queue.

Parameters:

  • event_name (str) – Event name. Refer to EventKind Enum.

  • data (object, optional) – Data associated with the event, by default None

Return type:

None

get_event(event_name)¶

Retrieve an event from the queue.

Parameters:

event_name (str) – Event name. Refer to EventKind Enum.

Returns:

EventData object if an event is available in the queue, None otherwise.

Return type:

EventData or None

Examples

>>> eventdata = TEM3.EventManager().get_event("ChgMag")
>>> type(data)
EventData
>>> eventdata.name
'ChgMag'
>>> eventdata.data
(300000, 'X', 'x300k')

regist_method(event_name, callback, nname)¶

Register a callback method for a specific event.

Parameters:

  • event_name (str) – Event name. Refer to EventKind Enum.

  • callback (callable) – Callback function to be executed when the event occurs.

  • nname (str) – Unique identifier for the callback.

Returns:

Dictionary containing all registered callbacks for the event.

Return type:

dict

Examples

>>> def hook_method(*args):
...     print("Event occurred:", args)
...
>>> TEM3.EventManager().regist_method("ChgMag", hook_method, "my_hook")
{'my_hook': <function hook_method at 0x...>}
>>> TEM3.EOS3().UpSelector()  # This will trigger the event and call hook_method
Event occurred: (300000, 'X', 'x300k')
unregist_method(event_name, nname)¶

Unregister a callback method from a specific event.

Parameters:

  • event_name (str) – Event name. Refer to EventKind Enum.

  • nname (str) – Unique identifier for the callback to remove.

Return type:

None

Examples

>>> TEM3.EventManager().unregist_method("ChgMag", "my_hook")
>>> TEM3.EOS3().UpSelector() # This will no longer trigger the hook_method
>>>
method_list(event_name)¶

Get list of all callback methods registered for a specific event.

Parameters:

event_name (str) – Event name. Refer to EventKind Enum.

Returns:

List of callback functions registered for the event.

Return type:

list

Examples

>>> TEM3.EventManager().method_list("ChgMag")
>>> []
