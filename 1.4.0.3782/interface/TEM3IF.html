PyJEM.TEM3 Interface Reference¶

This notebook provides a version compatibility reference for PyJEM.TEM3.

For each class and method in PyJEM.TEM3, the table shows which PyJEM versions support it.

The classes covered are:

  • Apt3 — Aperture control

  • Camera3 — Camera and shutter control

  • Def3 — Deflector control

  • EOS3 — Electron Optical System (magnification, mode, focus)

  • FEG3 — Field emission gun control

  • Filter3 — Energy filter control

  • GUN3 — Electron gun control

  • HT3 — High tension control

  • Lens3 — Lens control

  • MDS3 — MDS control

  • Nitrogen3 — Nitrogen system control

  • Scan3 — Scan control

  • Stage3 — Stage control

  • VACUUM3 — Vacuum system control
