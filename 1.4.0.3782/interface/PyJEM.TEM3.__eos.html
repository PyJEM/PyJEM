GetFunctionMode()¶

Get imaging function mode.

Returns:

A tuple (index, name) containing:

  • index (int) - Function mode index

  • name (str) - Function mode name

In TEM mode: 0 = MAG, 1 = MAG2, 2 = LowMAG, 3 = SAMAG, 4 = DIFF In STEM mode: 0 = Align, 1 = SM-LMAG, 2 = SM-MAG, 3 = AMAG, 4 = uuDIFF, 5 = Rocking

Return type:

list

Example

>>> TEM3.EOS3().GetFunctionMode()
[0, 'MAG']

Parameters:

brightness value.
