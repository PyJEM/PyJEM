PyJEM.eds.acquisition.set_analyzer_settings(param)¶

Change the EDS Analyzer settings. Pass a ProcessTime array with 4 elements to the Body parameter. Each array element corresponds to a detector and is applied in the order Detector 1, 2, 3, 4.

Parameters:

param (dict) –

Analyzer settings payload.

key

type

value

ProcessTime

list[str]

List of ProcessTime values to apply to detectors 1 through 4. The list must contain exactly 4 elements.

Returns:

The returned value is a dictionary. A description of each item is provided below.

key

type

value

Version

str

API version string.

ProcessTime

list[str]

List of ProcessTime values applied to detectors 1 through 4. The list contains exactly 4 elements, each corresponding to a detector in order.

Return type:

dict

Warning

If the array contains more than 4 elements, any additional elements are ignored. If it contains fewer than 4 elements, an error occurs.

Example:

Passing ["T2", "T2"] will result in an error response after the settings are applied to detectors 1 and 2.

Notes

The settings apply even when any arbitrary string is entered.

Example:

Passing ["a", "a", "a", "a"] sets "a" as the ProcessTime for detectors 1, 2, 3, and 4.

Examples

>>> from PyJEM import eds
>>> eds.set_analyzer_settings({'ProcessTime' : ['T1','T2','T3','T4']})
{
    "ProcessTime": [
        "T3",
        "T3",
        "T3",
        "T3"
    ],
    "Version": "2.0.0"
}

list[str]

List of position states for each detector. The list contains 4 elements in the following order: [Detector1, Detector2, Detector3, Detector4].

PyJEM.eds.acquisition.get_acquisition_settings()¶

Retrieve acquisition settings from the EDS detector.

Returns:

The returned value is a dictionary. A description of each item is provided below.

key

type

value

Version

str

API version string.

CollectionMode

str

Data acquisition mode. One of "LiveTime" or "RealTime".

  • "LiveTime": Effective measurement time per scan point.

  • "RealTime": Fixed duration per operation point.

EDSOutput

str

Output format of the data. One of "Spectrum" or "DataCube".

  • "Spectrum": Outputs only spectrum data.

  • "DataCube": Outputs both spectrum and cube data.

SpectrumEnergyRange

int

Energy range of the spectrum data. One of 1024, 2048, or 4096.

EnableCubeExport

bool

Whether to enable cube data export. If False, a 2D image integrated along the energy axis is returned.

Return type:

dict

Examples

>>> from PyJEM import eds
>>> eds.get_acquisition_settings()
{
    "CollectionMode": "RealTime",
    "EDSOutput": "DataCube",
    "SpectrumEnergyRange": 2048,
    "Version": "2.0.0"
}
